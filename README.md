# penjumlahan-matriks
Untuk menjumlahkan dua buah matriks dengan ukuran (baris dan kolom) yang sama, kemudian menampilkan hasilnya ke layar.
Menghitung dan menampilkan hasil penjumlahan dua buah matriks dengan ukuran yang sama menggunakan array dua dimensi dan perulangan bersarang (nested loop).
